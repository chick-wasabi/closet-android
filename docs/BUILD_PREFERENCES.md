# Closet build agreement

Native Kotlin / Compose Android app. Fully local storage, no account, ads, server, paid APIs, or implemented AI.
Commit cohesive changes and push to main as requested. Never force push.
User explicitly requests a debug APK build and Actions artifact on every push (overrides manual-build skill default). No release publication or tags requested.
Target phone: OnePlus 13R, 1264 × 2780 pixels, 6.78-inch display. Use adaptive Compose layouts and test this aspect ratio with large text; real-phone visual testing remains necessary.
