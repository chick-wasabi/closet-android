Commit cohesive changes and push to main as requested. Never force push.

Use the GitHub no-reply commit email chick-wasabi@users.noreply.github.com. GitHub rejects this repository’s pushes if commits expose the user’s protected private email.

Visual direction: cobalt, ink, and cool white; condensed sans-serif headings and a fashion contact-sheet layout. The user explicitly rejected the previous ivory/olive, serif, rounded-card theme. Read [DESIGN_DIRECTION.md](DESIGN_DIRECTION.md) before changing the UI.
